# CKAD Exam Preparation

## 📖 About

**Certified Kubernetes Application Developer (CKAD)** - Hands-on, performance-based exam testing your ability to design, build, and deploy cloud-native applications on Kubernetes.

- **Duration:** 2 hours | **Format:** Live terminal | **Pass:** 66% | **Cost:** $395 USD (includes retake + Killer.sh)
- **Who:** Developers, DevOps engineers, cloud practitioners

⚠️ **Questions generated by AI** ([CodeMie](https://github.com/codemie-ai/codemie-code)) - NOT official exam questions. For official practice: [Killer.sh](https://killer.sh), [CKAD Curriculum](https://github.com/cncf/curriculum)

## 🎯 Quick Start

```bash
# 1. Clone repo
git clone https://github.com/cfccfelipe/certified-kubernetes-application-developer-ckad.git
cd certified-kubernetes-application-developer-ckad

# 2. Memorize cheatsheet
cat EXAM-DAY-CHEATSHEET.md

# 3. Start practicing (TERMINAL ONLY!)
cd Practice-Questions/01-Core-Concepts/
cat README.md && cat COMMANDS.md

# 4. Try a question (8-10 min timer)
vim solution.yaml
kubectl apply -f solution.yaml

# 5. Check solution and clean up
cat solution-01.md
kubectl delete pod <pod-name>
```

**Daily Goal:** 3-5 questions | 8-10 min each | Terminal only (vim/nano)

## 📋 Exam Rules

### ✅ Allowed
- kubernetes.io docs (multiple tabs)
- Terminal editors (vim, nano)
- kubectl commands
- Copy/paste from docs

### ❌ NOT Allowed
- IDEs (VS Code, etc.)
- External websites (only kubernetes.io)
- Personal notes/cheatsheets
- AI tools

### 🎓 Study Strategy
1. **Memorize** EXAM-DAY-CHEATSHEET.md
2. **Practice** finding docs quickly on kubernetes.io
3. **Master** vim/nano for YAML editing
4. **Use** imperative commands (faster than YAML)
5. **Terminal only** - no IDEs during practice

## 💡 Essential Tips

alias k=kubectl

alias kd='kubectl describe'
export do='--dry-run=client -o yaml'

**Top 10 Tips:**
1. **Terminal only** - No VS Code during practice

4. Use `kubectl explain` instead of docs

6. Always verify: `kubectl get/describe`

## 🎓 Exam Day Strategy

**First 2 minutes - Setup:**
```bash
alias k=kubectl
alias kg='kubectl get'
alias kd='kubectl describe'
export do='--dry-run=client -o yaml'
echo "set tabstop=2 shiftwidth=2 expandtab" >> ~/.vimrc
```

**Strategy:**
1. Read all questions, flag hard ones
2. Do easy questions first
3. Use `kubectl explain` when stuck
4. Verify with `kubectl get/describe`
5. Use vim/nano only (no IDEs!)
6. Check namespace and labels
7. Last 15 min: verify all answers

**Key Points:**
- 8-10 min max per question
- Imperative commands > YAML
- Skip if stuck, return later
- Only kubernetes.io allowed
- 66%+ to pass
